# 초2 순간/단기 기억력(작업기억) 훈련 앱 — 개발 계획

## Context
초등 2학년 아이가 방금 배운 개념이나 영어 단어를 곧바로 잊어버리는 문제가 있습니다. Gemini 답변에서 제시한 원리를 놀이형 앱으로 만들어, 아이가 매일 10분 정도 즐겁게 훈련하고 부모는 진행 상황을 확인할 수 있게 하는 것이 목표입니다. 반영할 원리는 다음과 같습니다.
- 작업기억 훈련: 숫자 거꾸로 말하기, '시장에 가면', 여러 단계 지시 기억하기
- 불안을 낮추는 피드백
- 영어 단어는 소리·그림·상황과 연결하고, 여러 날에 걸쳐 반복 노출

**사용자와 정한 결정 사항**
| 항목 | 결정 |
|---|---|
| 기술 | **Flutter** 하나로 **Android 앱(APK)과 웹(PWA)**을 함께 빌드. 맥북에서 Android 개발 가능 (Android Studio만 설치하면 됨) |
| 배포 | 지인·소수 공유. 서버와 로그인 없이 **기기 안에 데이터 저장** |
| 사용 방식 | 아이 혼자 하는 모드와 부모와 함께 하는 모드 |
| MVP 훈련 | 숫자 거꾸로 / 시장에 가면 / 지시 따르기 / 영어 단어 (숫자·한글 공부는 2차 버전) |
| 입출력 | **TTS로 듣고 터치로 답하기** |
| 영어 단어 | 기본 단어 세트에 부모가 추가. 듣고 그림 4개 중 고르기, 간격 반복 복습 |
| 동기·기록 | 자동 난이도 조절, 스티커 보상, 부모용 기록 화면, 아이 여러 명 프로필 |
| 함께 모드 | 주고받기 턴 게임, 오프라인 놀이 미션 카드 |

| 테스트 | 안드로이드 실제 기기 있음, 크롬 병행 |
| 진행 | 단계별로 구현하고, 단계마다 크롬과 실제 기기에서 확인 |

## 현재 환경 (확인 완료)
- Flutter 3.38.7 / Dart 3.10.7, Apple Silicon. Chrome 빌드는 바로 가능.
- Android toolchain이 없음 → Android Studio 설치 필요.
- 시스템 JDK가 11이라 최신 Android Gradle에는 너무 낮음 → Android Studio에 들어 있는 JDK(17 이상)를 사용하도록 설정.
- Xcode 없음 → iOS는 범위 밖. 아이폰 지인에게는 웹(PWA) 링크로 대응.
- 프로젝트 폴더는 비어 있었고 git도 없었음 (0단계에서 생성).

## 기술 스택
- 상태 관리: `flutter_riverpod`
- 화면 이동: `go_router`
- 로컬 저장: `hive_ce` (Android와 웹 IndexedDB를 모두 지원하고 설정이 단순함)
- 음성: `flutter_tts` (Android TTS 엔진과 웹 SpeechSynthesis 지원. 한국어 ko-KR, 영어 en-US)
- 그래프: `fl_chart`
- 보상 연출: `confetti`
- 테스트: `flutter_test`로 핵심 로직 단위 테스트

## 앱 구조와 화면 흐름
프로필 선택(이모지 아바타와 이름) → **홈**
- **오늘의 코스** (큰 버튼): 영어 복습 → 숫자 거꾸로 → 시장에 가면 → 지시 따르기 순서로 각 2~3분. 끝나면 스티커 1장.
- **자유 놀이**: 4가지 게임 타일
- **함께하기**: 주고받기 턴 게임, 놀이 미션 카드
- **스티커북**
- **부모 메뉴** (곱셈 문제로 잠금): 프로필 관리, 단어 관리, 기록, 미션 카드, 설정 (말하기 속도, 코스 길이)

### 피드백 원칙 (Gemini 답변 반영)
- "틀렸어" 대신 "숫자가 잠깐 도망갔네! 다시 잡아보자" 같은 부드러운 문구를 쓰고, 정답은 짧게 다시 보여줌.
- 시간 제한 압박은 두지 않음. 다시 듣기 버튼은 제공하되, 다시 들으면 별 보상이 1개 줄어듦.

## 게임 설계
**공통**
- 문항을 6개 정도 묶어서 한 판으로 진행.
- 자동 난이도 조절(staircase): 연속 2번 맞히면 한 단계 올리고, 연속 2번 틀리면 한 단계 내림. 프로필과 게임별로 현재 레벨을 저장.

1. **숫자 거꾸로**: TTS가 숫자를 1초 간격으로 읽음 → 아이가 숫자 키패드로 거꾸로 입력. 2자리부터 시작해 최대 7자리. 처음 3번은 바로 순서 연습 문항으로 시작.
2. **시장에 가면**: 매 라운드 물건이 하나씩 늘어나며 TTS가 "시장에 가면 사과도 있고, 우유도 있고…"를 읽음 → 이모지 격자(6~12칸)에서 순서대로 누름. 난이도는 시작 길이와 격자 크기로 조절.
3. **지시 따르기**: 색깔 상자 안에 이모지 물건을 배치하고, TTS가 "빨간 상자의 사과를 누르고, 그다음 강아지를 눌러"처럼 지시함 → 지시를 듣는 동안에는 화면을 가리고, 다 들은 뒤 순서대로 누름. 2단계 지시에서 시작해 최대 4단계, 색깔과 위치 조건을 추가해 난이도를 올림.
4. **영어 단어**
   - **익히기 카드**: 이모지, 단어, 소리, 짧은 예문("I'm hungry"), 한국어 뜻을 보여줌.
   - **퀴즈**: 단어 소리를 듣고 그림 4개 중 하나를 고름.
   - **간격 반복**: Leitner 상자 방식으로 당일 → 1일 → 3일 → 7일 → 14일 뒤 다시 출제. 틀리면 1단계로 돌아감. 하루 새 단어는 3~5개(설정에서 변경 가능).
   - **기본 단어**: 약 80개. 음식, 동물, 감정, 몸, 학교, 가족, 색깔 등 이모지로 표현 가능한 단어로 구성.
   - **부모 추가**: 영어 단어, 한국어 뜻, 이모지(키보드로 입력), 예문(선택)을 입력.

### 함께 모드
- **주고받기 턴 게임**: 시장에 가면의 2인 버전. 부모와 아이가 번갈아 기기를 넘겨받아, 지금까지의 목록을 순서대로 누른 뒤 새 물건을 하나 추가함. 틀리면 상대 차례로 넘어감.
- **놀이 미션 카드**: 기본 카드 약 20장. 예: 마트에서 살 물건 3개 기억하기, 그림책 줄거리 떠올리기, 2~3단계 심부름, 차 안에서 숫자 거꾸로 말하기, 포즈 따라 하기. 부모가 완료를 체크하면 스티커를 줌.

### 부모 기록 화면
- 게임별 최고 레벨(기억한 개수)의 날짜별 추이 그래프와 정답률
- 연속 학습 일수
- 자주 틀리는 영어 단어 목록
- 미션 완료 기록

## 진행 단계 (단계마다 크롬과 실제 기기에서 확인하고 다음 단계로)
0. **GitHub 준비와 첫 커밋** (사용자 요청으로 가장 먼저 진행)
   - `brew install gh` → 사용자가 직접 `! gh auth login`으로 브라우저 로그인 (SSH 키 대신 HTTPS와 gh 인증 사용)
   - git 사용자 정보 설정: 공개 저장소이므로 개인 이메일 대신 GitHub noreply 이메일(`ID+아이디@users.noreply.github.com`) 사용을 권장. 설정 전에 사용자에게 확인.
   - 현재 폴더에서 `flutter create --org io.develofun --project-name memory_playground --platforms=android,web .` 실행
   - README.md(앱 소개, 실행 방법)와 docs/PLAN.md(이 계획) 추가. Flutter 기본 .gitignore 확인 (키스토어와 `key.properties`는 제외 대상에 추가)
   - `git init -b main` → 첫 커밋 → `gh repo create memory-playground --public --source=. --push`
   - 공개 저장소이므로 아이 이름이나 사진 같은 개인정보는 코드와 시드 데이터에 넣지 않음
0-1. **환경 세팅**
   - `brew install --cask android-studio` → SDK와 cmdline-tools 설치 → `flutter doctor --android-licenses`
   - 필요하면 `flutter config --jdk-dir`로 Android Studio JDK 지정
   - 휴대폰 USB 디버깅으로 기본 앱 실행
   - **TTS 사전 검증**: 기기에서 한국어와 영어 음성이 나오는지 확인 (Google TTS 음성 데이터 설치 여부). 가장 큰 리스크라서 가장 먼저 확인.
1. **뼈대**: 테마(큰 글씨, 큰 터치 영역), 라우터, Hive, 프로필 생성·선택, 홈, 부모 잠금
2. **게임 공통 틀과 숫자 거꾸로**: 난이도 조절 로직과 단위 테스트, 결과 저장
3. **시장에 가면, 지시 따르기**: 지시 문장 생성기와 단위 테스트
4. **영어 단어**: 기본 단어, 간격 반복과 단위 테스트, 부모 단어 관리 화면
5. **오늘의 코스와 스티커북**: 보상 연출
6. **함께 모드**: 턴 게임, 미션 카드
7. **부모 기록 화면**: 그래프
8. **배포**
   - 서명 키스토어 생성 → `flutter build apk --release` → 지인에게 파일 공유 (출처를 알 수 없는 앱 설치 허용 안내문 포함)
   - `flutter build web`으로 PWA를 만들고, 공개 저장소이므로 GitHub Pages(GitHub Actions 자동 배포)로 무료 호스팅해서 아이폰 지인에게 대응.

## 범위 밖 (2차 버전 후보)
- 숫자·한글 공부 모드
- 기기 간 데이터 동기화와 백업 (1차는 기기 안에만 저장하므로 앱을 삭제하면 기록도 사라짐. JSON 내보내기·가져오기를 우선 후보로 검토)
- iOS 네이티브 앱, Play 스토어 등록, 음성 인식으로 말해서 답하기

## 검증 방법
- `flutter test`: 난이도 조절, 간격 반복 날짜 계산, 지시 생성기 단위 테스트
- `flutter run -d chrome`과 `flutter run -d <안드로이드 기기>`로 단계마다 직접 플레이
  - TTS 한국어·영어 음성
  - 터치 영역 크기
  - 난이도 오르내림
  - 앱 재시작 후에도 기록이 유지되는지
- 아이에게 실제로 시켜보고 지루함, 어려움, 문구 반응을 확인해 다음 단계에 반영
- 배포 단계: 다른 안드로이드 기기에 release APK를 설치해 처음부터 끝까지 확인. PWA는 크롬의 '앱 설치'와 휴대폰의 '홈 화면에 추가'로 확인.
